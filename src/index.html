Onde as ações validadas aconteceram, município por município. Cada ação é ligada ao mapa oficial do IBGE pelo código do município. Clique em um estado com dados para aproximar e em um círculo para ver as ações daquele lugar.

ⓘ
Protótipo. Por enquanto só o Comitê de Cultura do Paraná tem dados carregados. Os demais estados aparecem em cinza até que seus comitês preencham a planilha com o mesmo cabeçalho. O código do município usa a Divisão Territorial Brasileira (DTB) do IBGE, que é um estudo de codificação e difere da codificação do PNCC, que define códigos apenas para os estados.

Arraste para mover e use a roda do mouse para aproximar. Clique em um estado com dados para aproximar nele e em “Ver o Brasil inteiro” para voltar.
